# Griglia Instagram SANDER

12 post 1080×1350 (4:5) nello stile "run club": foto mosse effetto pellicola,
scritte a pennarello, grafite sgranato, lime SANDER, piccole info negli angoli.
Le foto in `photos/` sono generate con Higgsfield: persone inventate, scalze, senza marchi.

```bash
node scripts/content-grid/gen.mjs     # → out/*.jpg
```

Pubblica **dal 12 all'1**: su Instagram l'ultimo post finisce in alto a sinistra,
così la griglia appare nell'ordine dei file (01 in alto a sinistra).
Un post al giorno, la sera (18–21). I due post lime (06 e 10) danno il ritmo alla griglia.
