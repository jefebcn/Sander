# Caroselli Instagram — lancio Scopri

Formato 1080×1350 (4:5), slide in `out/`. Schermate vere dell'app su dati demo,
foto di sfondo generate con Higgsfield (`bg/`): persone inventate, scalze, senza marchi.

Rigenerare:

```bash
node scripts/store-demo-photos.mjs                    # foto demo sui profili locali
BASE=http://localhost:3000 node scripts/content-scopri/gen.mjs
```

Ordine consigliato: uno ogni 2–3 giorni, nelle ore serali (18–21).
